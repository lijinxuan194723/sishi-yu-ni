# 四时与你 1.9.4（Android）

发布日期：2026-09-11

## 本次更新

1.9.4 在 1.9.2 正式版的基础上继续打磨启动流程与时光手记，并新增夏彦人格与记忆模块的基础代码。

- 移除启动遮罩与开屏编排，进入应用后直接显示主界面与底部导航，不再有开屏等待。
- 时光手记的编辑器、新建按钮与笔记本浮层改用 Portal 渲染到 `document.body`，并按 `visualViewport` 动态调整编辑器高度，修复移动端键盘弹出时的遮挡与错位。
- 统一时光手记与聊天输入区的排版细节，修正输入框的对齐与高度。
- 新增 `lib/agent/`：夏彦人格（`constitution` / `persona-builder` / `style` / `situations`）与长期记忆（`memory/store` / `memory/types`）模块。该模块目前为独立代码，**尚未接入界面**。
- Android 版本号升级为 `1.9.4`，versionCode 为 `901004`。

## 版本号说明

- `1.9.3` 为本地中间构建，未单独发布，其改动已包含在 1.9.4 中；versionCode 由 `901002` 直接递增到 `901004`。

## 数据与安装说明

本版本不会主动清空本地存储。为了避免 Android 包身份或签名变化产生新的数据空间，后续正式 APK 必须保持同一 package 与同一 release signing key。

升级前仍建议在应用的“设置 → 日常与数据”中导出一次完整备份。
