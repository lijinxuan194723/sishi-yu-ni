# 四时与你 1.9.1（Android）

发布日期：2026-09-10

## 本次更新

1.9.1 在 1.9.0 正式版基础上加入“夏彦人物记忆 V2”。人物知识已经内置进 APK，不依赖运行时下载，也不需要用户手动导入资料。

- 内置 412 条夏彦结构化人物知识：人物基础 41 条、性格习惯 76 条、人物关系 38 条、能力兴趣 42 条、重要经历 155 条、日常细节 60 条。
- 聊天时按最近用户问题动态检索相关人物知识，只注入当前话题需要的少量条目，避免把完整知识库每轮重复发送给模型。
- 保留 A / A2 / B / C 来源可信度，冲突时优先高可信度资料。
- 将主线现实与“换日线”等平行/AU、梦境/特殊世界线隔离；只有用户明确讨论对应世界线时才允许召回。
- “夏彦原作人物知识”与“用户长期聊天记忆”分离。原作中“女主/两人”的事件默认作为角色背景和行为风格参考，不自动认定为当前用户亲历。
- 继续保留 1.9.0 的统一笔记、聊天附件、完整备份、四季昼夜联动、开屏动画等功能。

## 升级与数据连续性

1.9.1 采用 1.9.0 正式渠道的同一 Android 安装身份与同一签名证书，并将 versionCode 从 901000 提升到 901001。用户已经安装 1.9.0 时，可以直接安装 1.9.1 覆盖更新，不需要卸载旧版。

本次功能没有修改以下本地数据实现：

- `lib/companion.ts`：聊天、计划、手记、长期记忆等主存档结构；
- `lib/use-local-data.ts`：主存档 localStorage 读写；
- `lib/memos.ts`：统一笔记/备忘本地存储；
- `lib/full-backup.ts`：完整备份与恢复；
- `mobile/android/MainActivity.java`：Android WebView 数据环境与本地页面加载方式。

正式构建会把已发布的 1.9.0 APK 作为旧包进行升级校验，并强制检查：

- 1.9.0 与 1.9.1 的 Android package name 完全一致；
- 1.9.0 与 1.9.1 的签名证书 SHA-256 完全一致；
- 1.9.1 versionCode 高于 1.9.0；
- 1.9.1 显示名称仍为“ 四时与你 ”；
- 1.9.1 通过 `apksigner verify` 与 `zipalign`；
- 412 条人物知识的数量、分类、检索和 AU 隔离测试通过；
- 存档相关核心文件相对 1.9.0 没有发生修改。

满足这些条件时，Android 会把 1.9.1 识别为原应用升级，应用私有数据和 WebView 本地数据不会因为覆盖安装而被主动清除。

> 说明：任何应用都无法对设备故障、系统清理、存储损坏或用户手动清除数据作绝对保证。为了防范这些安装包之外的风险，仍建议升级前在“设置 → 日常与数据”导出一次软件完整备份。

## 人物知识说明

人物知识来自项目整理的夏彦公开资料数据库。人物事实保留来源等级与世界线边界；低可信度资料不会自动升级为官方确定事实。知识库主要用于增强人物一致性、经历记忆和日常细节，不替代用户自己的长期聊天记忆。
