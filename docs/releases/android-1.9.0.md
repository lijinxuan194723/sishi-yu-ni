# 四时与你 1.9.0（Android）

发布日期：2026-09-10

## 本次更新

- 将“手记 / 备忘”统一为一个笔记系统，支持笔记本、置顶、加星、搜索、心情标签、回收站与本地保存。
- 「悄悄话」新增图片与文件附件入口；图片可随本轮发送给支持视觉的兼容模型，常见文本文件可读取正文后随消息发送。
- 新增“软件完整备份 / 恢复”，覆盖聊天、计划、统一笔记、笔记本、学习与阅读记录、纪念日、外观及非敏感连接设置。
- API Key、天气 Token 等敏感凭据不会写入完整备份。
- 各页面专属操作统一到右上角，全局设置仅保留首页与桌面侧栏入口。
- 时光手记移除重复二级顶栏，保留单一页面顶栏。
- 聊天输入区将附件键与发送键归并到同一右侧操作区，并随春夏秋冬和昼夜主题切换。
- 开屏动画接入四季与昼夜主题，采用揭幕式进入主页；移动端底部导航在主页出现后独立延后显示。

## 升级与数据

1.9.0 正式 Android 安装包延续最近测试版 v12 的应用包身份与同一签名证书，同时使用更高的 versionCode。因此，从 v12 安装 1.9.0 时应由 Android 作为原应用更新处理，不需要卸载，原有 WebView 本地数据、聊天、计划、笔记和设置会继续保留。

发布构建会自动校验：

- 正式 APK 的包名必须与 v12 相同；
- 正式 APK 的签名证书 SHA-256 必须与 v12 完全一致；
- 正式 APK 的 versionCode 必须高于 v12；
- 应用显示名称为“ 四时与你 ”，不再带“测试”字样；
- APK 必须通过 `apksigner verify` 与 `zipalign` 校验。

虽然原地升级本身不会主动清除应用数据，仍建议升级前在“设置 → 日常与数据”导出一次软件完整备份，用于防范设备、系统或文件损坏等非应用升级因素。

## 兼容性说明

本次正式渠道优先保证最近连续测试版本（v12）的原地升级与数据延续。更早的 1.8.18 正式 APK 使用的是另一套历史安装身份，不能与本次 1.9.0 视为同一个 Android 原地升级链路；如仍在使用该历史版本，请先导出完整备份，再迁移到新的正式渠道。
