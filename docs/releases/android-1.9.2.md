# 四时与你 1.9.2（Android）

发布日期：2026-09-11

## 本次更新

1.9.2 基于已经完成真机验证的稳定代码发布，正式基线来自 `dev/local-work` 的已测试版本。

- 移除启动遮罩/开屏编排造成的等待与卡顿，进入应用后直接显示主界面与底部导航。
- 统一页面、弹窗、按钮和局部内容的交互节奏，减少突兀的瞬间切换。
- 季节与昼夜主题改为主题图片预加载完成后再切换，修复切季闪屏、颜色错位和旧画面残留。
- 四季相册在图片解码完成后再完成切换，避免白帧；连续快速切换时只采用最新请求。
- 时光手记搜索框、标签、卡片、编辑器、浮动按钮等统一跟随季节与昼夜主题。
- Android 版本号升级为 `1.9.2`，versionCode 为 `901002`。

## Release 排列规则

从 1.9.2 开始，GitHub Release 统一使用版本化标签：

- `android-four-seasons-v1.9.2`
- `android-four-seasons-v1.9.1`
- 后续版本继续按相同规则递增。

每次发布新正式版本时，新版本标记为 **Latest**。GitHub Release 页面按发布时间展示，因此最新发布的版本位于最前，旧版本依次保留在后面用于追溯。

## 数据与安装说明

本版本不会主动清空本地存储。为了避免 Android 包身份或签名变化产生新的数据空间，后续正式 APK 必须保持同一 package 与同一 release signing key。

升级前仍建议在应用的“设置 → 日常与数据”中导出一次完整备份。
