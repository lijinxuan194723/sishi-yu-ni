# 四时与你 1.9.5（Android）

发布日期：2026-09-11

## 本次更新

「他的此刻」里的**随身歌单**和**最近在读**，改成每天由内置的模型 API 自动更新。

- 每天打开应用时自动检查：当天还没有内容，就用「设置 → 聊天模型」里配置的模型 API 生成一份今日歌单和一本今日在读，生成结果按日期缓存在本机，同一天不会重复请求。
- 随身歌单：8 到 10 首华语作品，歌名与演唱者由模型给出；「换一首」在今日歌单内切换，标题会显示「今日 · N 首」。
- 最近在读：一本书，附作者、类型、简介和一句阅读提示；排在书单最前并标注「今日推荐」，原有书目与「添加书籍」不受影响。
- 两个区块各新增一个刷新按钮，随时可以重新生成当天内容。
- 未配置模型或请求失败时，自动回退到内置的本地内容，界面不会空白；失败原因显示在歌单下方。
- Android 版本号升级为 `1.9.5`，versionCode 为 `901005`。

## 数据与安装说明

本版本不会主动清空本地存储。为了避免 Android 包身份或签名变化产生新的数据空间，后续正式 APK 必须保持同一 package 与同一 release signing key。

升级前仍建议在应用的“设置 → 日常与数据”中导出一次完整备份。
